# NZ Enhanced App

Enhanced New Zealand map with demographics, filtering UI, and a first
reviewer-facing OSM verification surface.

- index.html is the entry point.
- verification.html is the static NZ OSM verification task map. It uses a
  greyscale basemap and individual review markers. It includes provisional
  2013, 2018, and 2023 target-year controls derived from reviewed status fields
  or OSM lifecycle tags. The public feedback pilot is read-only until secure
  staging exists.
- Add `?demo=1` to preview the local RA action builder and nomination
  controls. Demo mode can generate a spreadsheet-ready evidence row and review
  JSON locally, does not save or submit data, and should not be used for
  private or sensitive data.
- js/ holds application logic.
- data/ holds prebuilt GeoJSON/JSON inputs generated by scripts.

Regenerate inputs via the scripts in `scripts/` (R and Python), which write to
`apps/regions/nz/data`.

Regenerate the verification task layer with:

```sh
uv run scripts/build_nz_verification_tasks.py
```
