# Vanuatu Source-First Test Portal

These entry points are a temporary Vanuatu test surface over the shared Convex
task and review backend.

- `verification.html` opens the Vanuatu source-first RA view with target years
  1989, 1999, 2009, and 2020.
- `review.html` opens the reviewer queue filtered to Vanuatu submissions.

Both pages route through the shared static New Zealand portal implementation
with `country=vu`. This keeps the first Vanuatu test in the same provisional
task store while the final country-specific portal is still being designed.
