# Immersive exploration — options brief (2026-09-10)

Status: OPTIONS BRIEF with a staged keyless pilot. Nothing here is wired into navigation, no key is added, and no ruling is presumed. JB raised the idea on 2026-09-10 after seeing [gods-eye-view](https://github.com/bilawalsidhu/gods-eye-view): "looking ahead, it would be wonderful to build in immersive experiences for PoW exploration, setting aside any interest in the research." This brief sets out what an immersive layer could be, what each rendering route costs in keys, money, licence and effort, which experiences the project's data already support, and what needs a ruling. Every price and term below was read from the cited page on 2026-09-10; anything read from memory or a search snippet is marked UNVERIFIED.

## 1. What gods-eye-view does, and what transfers

gods-eye-view is a vanilla JavaScript, CesiumJS and Vite app that renders live data layers on a photorealistic globe. Its README describes Esri satellite imagery with keyless terrain, OpenStreetMap as the fallback when Esri is unreachable, and photorealistic 3D as an opt-in: "add a Cesium ion token for eligible personal, non-commercial use, or a Google Maps key for the direct, metered route" ([README](https://github.com/bilawalsidhu/gods-eye-view)). Its camera modes (cockpit and fly-through), scene director with shareable URLs, and hardened server-side key proxy are the parts worth borrowing. Its [DATA_SOURCES.md](https://github.com/bilawalsidhu/gods-eye-view/blob/main/DATA_SOURCES.md) is explicit that "The MIT grant covers the source code only — it does NOT extend to third-party data or visual assets", and that Google Maps content "may not be cached, stored, rehosted, or committed — this app only ever uses it live" (the repository's paraphrase; Google's own wording is quoted in section 2.4).

Three things transfer directly to religionmap.org: the scene-director idea (a tour is a list of camera keyframes with a title card, addressable by URL), the keyless-first stance (imagery and terrain that need no key, with metered sources as opt-ins), and the discipline of never committing or caching third-party content. What does not transfer is the CesiumJS and Google Photorealistic 3D Tiles stack, for the licence and terms reasons in section 2.4.

## 2. Rendering options and their fit with the MapLibre stack

The live map runs MapLibre GL JS 3.6.1 from unpkg with OpenStreetMap raster tiles as the basemap (JB ruling 2026-08-28) and project vector tiles from Cloudflare R2. The shared runtime (`apps/regions/_shared/region-map.js`) serves the global map and about a hundred country pages. Any immersive feature therefore has two possible homes: a standalone page that loads a newer MapLibre, or a mode of the shared runtime after a library upgrade. The pilot takes the first route.

### 2.1 MapLibre GL JS globe, terrain, hillshade and building extrusions

- Current release: v6.9.0, published 2026-09-09; the release notes list terrain and globe fixes only ([releases](https://github.com/maplibre/maplibre-gl-js/releases)). v6.0.0 (2026-07-22) made two breaking changes that matter here: "The UMD bundles (`maplibre-gl.js`, `maplibre-gl-csp.js`) are no longer published" and "WebGL (v1) support has been removed; WebGL2 is now required" ([v6.0.0 notes](https://github.com/maplibre/maplibre-gl-js/releases/tag/v6.0.0)). A page must therefore load the ESM build (`dist/maplibre-gl.mjs`); the docs state the worker "is auto-detected from the imported module's URL and laundered through a same-origin Blob URL", so a CDN import works on a static site ([quick start](https://maplibre.org/maplibre-gl-js/docs/)). The last UMD line is 5.x (5.24.0 on npm), which also has globe and terrain.
- Globe projection arrived in v5.0.0 (2024-12-31) with "Support Terrain in Globe projection" in the same release ([v5.0.0 notes](https://github.com/maplibre/maplibre-gl-js/releases/tag/v5.0.0)). The official example "Create a Heatmap layer on a globe with terrain elevation" sets `projection = { type: 'globe' }` and `terrain = { source, exaggeration: 1 }` together ([example](https://maplibre.org/maplibre-gl-js/docs/examples/create-a-heatmap-layer-on-a-globe-with-terrain-elevation/)). At high zoom the globe transitions to Mercator automatically, so terrain-draped street-level views behave as on a flat map.
- Terrain has been in GL JS since 2.2.0 (2022-08-10); raster-dem sources accept `encoding: terrarium | mapbox | custom` ([style spec: terrain](https://maplibre.org/maplibre-style-spec/terrain/), [sources](https://maplibre.org/maplibre-style-spec/sources/)). Hillshade and `fill-extrusion` layers are long-standing ([layers](https://maplibre.org/maplibre-style-spec/layers/)).
- Reduced motion: `AnimationOptions.essential` — "If `true`, then the animation is considered essential and will not be affected by `prefers-reduced-motion`" — so a tour can honour the user's setting by leaving it false or by using `jumpTo` ([API](https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/AnimationOptions/)).
- Mobile caveats from the tracker: terrain memory growth on interaction (#1291), "Terrain performance needs improvement, especially during rotation/pitch and close-range interaction" ([#7363](https://github.com/maplibre/maplibre-gl-js/issues/7363)), and "Map eventually crashes on iOS devices" on repeated reloads ([#7667](https://github.com/maplibre/maplibre-gl-js/issues/7667)). The pilot lowers exaggeration and drops building extrusions on phones for this reason.
- Licence BSD-3-Clause; `maplibre-gl.mjs` measured at 585,178 bytes uncompressed from jsdelivr.

### 2.2 Terrain (DEM) sources

- **Mapterhorn** (used by the pilot). MapLibre's own "3D Terrain" and globe-terrain examples use `https://tiles.mapterhorn.com/tilejson.json` with no key ([3D terrain example](https://maplibre.org/maplibre-gl-js/docs/examples/3d-terrain/)). The TileJSON declares `encoding: terrarium`, `tileSize: 512`, WebP tiles and the attribution "© Mapterhorn"; a GET with an `Origin` header returns `Access-Control-Allow-Origin: *`. The data page describes "Terrarium-encoded terrain rgb tiles as webp images with 512 pixel width", offers PMTiles archives (`planet.pmtiles` for z0–12 plus regional z13–17 files) for self-hosting, and notes "Cloudflare is generously supporting Mapterhorn with R2 Object Storage, Workers, and bandwidth" ([data access](https://mapterhorn.com/data-access/)). Licence CC BY 4.0 (stated in the Re:Earth Terrain README, which builds on Mapterhorn; the Mapterhorn attribution page itself was not fetched — UNVERIFIED as a direct quotation). Probed on 2026-09-10 over Christchurch: tiles served at z11–z15, 404 above; sea tiles at low zoom also 404, which MapLibre treats as empty.
- **AWS Terrain Tiles (Terrarium)**, the Mapzen/tilezen dataset on the Registry of Open Data. Keyless and live: `https://s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png` returned HTTP 200 with `Access-Control-Allow-Origin: *` ([registry](https://registry.opendata.aws/terrain-tiles/)). Attribution is per source and includes a New Zealand line: "New Zealand terrain data Copyright 2011 Crown copyright (c) Land Information New Zealand and the New Zealand Government (All rights reserved)", LINZ 8 m DEM under CC BY 3.0 NZ ([attribution](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)). Two cautions from the docs: "The S3 tiles are meant for efficient networking with EC2 resources only" and "The Amazon S3 endpoints are not cached using Cloudfront" ([use-service](https://github.com/tilezen/joerd/blob/master/docs/use-service.md)). The LINZ 8 m source may give better relief over New Zealand than Mapterhorn's global 30 m base; the pilot began on AWS and moved to Mapterhorn because Mapterhorn is built for browser use.
- **MapTiler terrain-rgb-v2** on the existing plan. Needs the key (a keyless request returns 403). Pricing: Free "100k/month" for "testing, personal or non-commercial use"; Flex $30/month for 500k requests then "$0.15/1k requests"; the FAQ states "Tile API Requests are billed for usage of MapTiler maps with third-party SDKs", so every DEM tile counts against the quota ([pricing](https://www.maptiler.com/cloud/pricing/), [guide](https://docs.maptiler.com/guides/maps-apis/maps-platform/how-to-build-a-3d-map-with-maplibre-v2-gl-js/)). A pitched terrain view fetches many DEM tiles, so this route would erode the 100k allowance the portal already uses for imagery.
- **Mapzen/Nextzen**: "winding down this service", no new signups ([developers.nextzen.org](https://developers.nextzen.org/)). Not an option.
- **Re:Earth Terrain** (gods-eye-view's keyless terrain): quantized-mesh and raster endpoints, Mapterhorn-derived, CC BY 4.0, and its README says "For MapLibre, Mapterhorn is the recommended" source ([reearth-terrain](https://github.com/reearth/reearth-terrain)).

### 2.3 Buildings from open vector tiles

- **OpenFreeMap** (used by the pilot). "there's no registration, no user database, no API keys, and no cookies"; "there are no limits on the number of map views or requests"; service offered as-is with no uptime guarantee ([openfreemap.org](https://openfreemap.org/), [ToS](https://openfreemap.org/tos/)). Its OpenMapTiles schema carries `render_height` ("An approximated height from levels and height of the building or building:part") and `render_min_height` in the `building` layer ([schema](https://openmaptiles.org/schema/)). Attribution: OpenFreeMap © OpenMapTiles, data from OpenStreetMap (ODbL). A probe of `https://tiles.openfreemap.org/planet` returned a dated build with CORS `*`.
- **Protomaps PMTiles on R2** (self-host route). The planet basemap is "roughly 120 gigabytes, including zoom levels from 0 to 15", distributed as an ODbL produced work; the `buildings` layer has `height` and `min_height` ([downloads](https://docs.protomaps.com/basemaps/downloads), [layers](https://docs.protomaps.com/basemaps/layers)). Deploying on Cloudflare needs a Worker on the project's own zone; R2 costs "$0.015 / GB-month", Class B "$0.36 / million requests", egress free, with 10 GB and 10 M reads free per month ([deploy](https://docs.protomaps.com/deploy/cloudflare), [R2 pricing](https://developers.cloudflare.com/r2/pricing/)). A New Zealand extract would be small (size UNVERIFIED). This is the route if OpenFreeMap's as-is service ever becomes a risk.
- **MapTiler Planet v3** on the existing plan: same height fields, key required, counts against the quota ([schema](https://docs.maptiler.com/schema/planet/)).
- **OSM Buildings**: separate renderer over plain http anonymous tiles; not worth adding beside OpenFreeMap ([repo](https://github.com/OSMBuildings/OSMBuildings)).

### 2.4 CesiumJS, Cesium ion and Google Photorealistic 3D Tiles

- **Cesium ion pricing**: Community "Free (individual)" for "Personal and non-commercial use" with "Google Photorealistic 3D Tiles 1,000 root tiles / month"; Commercial "$149/month (individual)"; Premium "$499/month (individual)". The FAQ says a paid licence is needed "If you are working on a government project, or If you are working on funded educational research, or If you exceed the usage limits", and the free account covers "Unfunded educational activities" ([pricing](https://cesium.com/platform/cesium-ion/pricing/)). A funded university research project therefore falls on the paid tier by Cesium's own reading. The terms also require that "the 'Cesium ion' logo must be prominently displayed on the main application window" ([ToS](https://cesium.com/legal/terms-of-service/)), and Google content through ion carries Google's rule: "You will not use the Google Maps Content with or near a non-Google map in a Your Application" ([terms for Google](https://cesium.com/legal/terms-for-google/)). Cesium's ecosystem grants are cash awards, not ion credits ([grants](https://cesium.com/cesium-ecosystem-grants/)).
- **CesiumJS** itself is Apache-2.0 and usable without ion; `Cesium.js` 1.145 measured at 6,018,837 bytes minified plus workers and assets ([downloads](https://cesium.com/downloads/)). That is ten times the MapLibre bundle.
- **Google Map Tiles API, Photorealistic 3D Tiles**: 1,000 free root tileset requests a month, then "$6.00 per 1,000"; a root request "allows for at least three hours of tile requests" ([pricing](https://developers.google.com/maps/billing-and-pricing/pricing), [3D Tiles](https://developers.google.com/maps/documentation/tile/3d-tiles)). The policies page states "you must not pre-fetch, index, store, or cache any Content except under the limited conditions stated in the terms" ([policies](https://developers.google.com/maps/documentation/tile/policies)).
- **The binding clause**. Google Maps Platform Terms 3.2.3(e), "No Use With Non-Google Maps": "Customer will not use the Google Maps Core Services with or near a non-Google Map in a Customer Application. For example, Customer will not (i) display or use Places content on a non-Google Map, (ii) display Street View imagery and non-Google Maps on the same screen, or (iii) link a Google Map to non-Google Maps Content or a non-Google Map" ([terms](https://cloud.google.com/maps-platform/terms)). Photorealistic 3D Tiles cannot be rendered over or beside the MapLibre and OpenStreetMap map. Clause (ii) also bears on the existing Street View thumbnails in the map popups; this is flagged as ruling R-I3 below.
- **Credits**: Google for Nonprofits excludes "a school, academic institution, or university" ([eligibility](https://www.google.com/nonprofits/eligibility/)); whether Google Cloud research credits can be spent on Maps Platform is UNVERIFIED ([researchers](https://cloud.google.com/edu/researchers)).

### 2.5 Street-level imagery: Google Street View and Mapillary

- **Street View**: Static API 10,000 free requests a month then "$7.00 per 1,000"; Dynamic Street View 5,000 free then "$14.00 per 1,000"; Maps Embed "available at no charge" ([pricing](https://developers.google.com/maps/billing-and-pricing/pricing), [embed](https://developers.google.com/maps/documentation/embed/usage-and-billing)). "You may use a standalone Street View object without a map" ([JS docs](https://developers.google.com/maps/documentation/javascript/streetview)), but 3.2.3(e)(ii) bars a panorama on the same screen as the OpenStreetMap map. The Service Specific Terms permit caching only the `pano_ID` ([service terms](https://cloud.google.com/maps-platform/terms/maps-service-terms)). A plain link that opens Google Maps in a new tab uses no Maps Platform service; the pilot uses that.
- **Mapillary**: every request to `graph.mapillary.com` and `tiles.mapillary.com` must carry a client or user token; limits of 60,000 entity requests a minute and 50,000 tile requests a day per app ([API](https://www.mapillary.com/developer/api-documentation)). Imagery is CC BY-SA 4.0 and the terms require the Mapillary logo and a link back ([terms](https://www.mapillary.com/terms)). `mapillary-js` 4.1.2 is MIT and browser-only (1,092,073 bytes) ([repo](https://github.com/mapillary/mapillary-js)). New Zealand coverage UNVERIFIED. A client token is free, so this is the keyed-but-costless street-level route, and it sits comfortably beside an OpenStreetMap basemap.

### 2.6 deck.gl and three.js overlays

deck.gl 9.4.0 (2026-09-05, MIT) ships `@deck.gl/maplibre` with "overlaid and interleaved rendering with MapLibre GL JS v4, v5, and the recently released v6"; the docs warn that "the deck.gl data with z=0 are rendered at the sea level and not aligned with the terrain surface" ([what's new](https://deck.gl/docs/whats-new), [overview](https://deck.gl/docs/api-reference/mapbox/overview)). The full bundle is 2,073,497 bytes. MapLibre's docs carry three.js custom-layer examples for a 3D model on a flat map, on the globe, and on terrain, plus "Add 3D tiles using three.js" via `3d-tiles-renderer` (Apache-2.0) ([examples](https://maplibre.org/maplibre-gl-js/docs/examples/)). These are the tools for arcs, animated flows, and any 3D model of a building, and they need no key.

### 2.7 360 photos, photogrammetry and gaussian splats of interiors

Viewers: Pannellum 2.5.7 (MIT, "just 21kB gzipped"), Photo Sphere Viewer 5.15.1 (MIT, three.js-based, marker tours), Marzipano 0.10.2 (Apache-2.0, "55KB when gzipped") ([Pannellum](https://github.com/mpetroff/pannellum), [PSV](https://photo-sphere-viewer.js.org/), [Marzipano](https://www.marzipano.net/)). Splats: GaussianSplats3D is "no longer in active development" with "Sub-optimal performance on mobile devices" ([repo](https://github.com/mkkellogg/GaussianSplats3D)); Spark 2.1.0 (MIT, World Labs) supports `.spz`, `.splat`, `.ply` and mobile ([sparkjs.dev](https://sparkjs.dev/)). File sizes UNVERIFIED; expect several megabytes per 8k equirectangular photo and tens to hundreds of megabytes per splat.

Consent is the governing constraint, not the technology. The Church of England's guidance states that "Attendance at a church service reveals religious belief, which is a special category data under GDPR" and that consent is unnecessary only when no congregant is identifiable ([guidance](https://www.churchofengland.org/resources/digital-labs/blogs/filming-and-photography-churches-consent-and-gdpr)). Te Mana Raraunga's principles require that "Free, prior and informed consent (FPIC) shall underpin the collection and use of all data from or about Māori" and that "Māori shall decide which Māori data shall be controlled (tapu) or open (noa) access" ([principles](https://www.temanararaunga.maori.nz/principles-of-maori-data-sovereignty)). Renfrew et al. (2026, JRSNZ) state that "using marae images for research would require the explicit consent of both the rangatahi who took the images and the marae committee" ([PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC12965020/)). The project's standing policy already bars personal details of living people and keeps culturally sensitive material away from external models; interior imagery adds a consent protocol on top, and marae and wāhi tapu stay out of any imagery pipeline absent FPIC.

### 2.8 WebXR on phones and headsets

caniuse lists Safari on iOS as "Not supported", macOS Safari "Disabled by default", Chrome for Android "Partial support" ([caniuse](https://caniuse.com/webxr)). visionOS Safari 18 added immersive WebXR (`immersive-vr`, hand tracking) ([WebKit](https://webkit.org/blog/15443/news-from-wwdc24-webkit-in-safari-18-beta/)); the Meta Quest browser supports immersive-ar passthrough ([Meta](https://developers.meta.com/horizon/documentation/web/webxr-mixed-reality/)). MapLibre has no WebXR mode; a three.js or A-Frame scene would own the headset session and take the project's data as input. This is a later-stage idea, and iPhone users are excluded from it today.

### 2.9 Accessibility

WCAG 2.2.2 (level A) requires a mechanism to "pause, stop, or hide" moving content that starts automatically and lasts more than five seconds ([WCAG](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)); `prefers-reduced-motion` has been baseline since January 2020 ([MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion)). MapLibre's keyboard handler pans with the arrow keys, zooms with `+` and `-`, and rotates and pitches with Shift plus arrows ([KeyboardHandler](https://maplibre.org/maplibre-gl-js/docs/API/classes/KeyboardHandler/)). Canvas content is invisible to screen readers, so a text itinerary of the tour stops is the accessible equivalent.

## 4. Experience design ideas specific to places of worship

Each idea is marked with what the existing data support today. The two data products in play are the NZ dated-places product (`apps/regions/nz/data/dated_places.geojson`: 1,313 point features carrying OpenStreetMap `start_date` and `end_date` tags, of which 51 are Anglican churches in Canterbury) and, once reviewed occupancies exist, the features `scripts/build_occupancy_dated_places.py` merges into the same file with `source: "reviewed_occupancy"` ([slider brief](public-map-occupancy-slider-brief-2026-09-02.md)).

1. **Fly-to tours across a denomination's history.** A tour is an ordered list of sites with a camera per stop and a title card drawn from the data. Supported today from the dated-places product; the pilot runs eight Canterbury Anglican stops. The weakness is the source: OpenStreetMap `start_date` tags are uneven, and the pilot exposes one error in plain view, the Transitional Cathedral (OSM way 101123036) carrying `start_date=1864`, the foundation year of the stone cathedral it replaced after the 2011 earthquake. Reviewed occupancies will replace such tags site by site; the tour engine reads whichever the product carries.
2. **A time slider through census years in 3D.** Supported today: the pilot's Year panel filters dated places by the alive predicate used on the country maps. Country maps keep the census-wave slider by ruling R7 (2026-09-02); a continuous slider on a standalone immersive page does not conflict with that ruling, but a ruling should say so (R-I5).
3. **"Stand at the door".** The evidence popup with a street-level view of the entrance. Supported today as a link that opens Google Maps' panorama in a new tab (no key, no Maps Platform service used). An embedded panorama beside the map is barred by Google's terms; a Mapillary viewer is the compliant embedded route where coverage exists.
4. **A scene director with shareable URLs.** Supported in a first form: the pilot writes the camera (`view=zoom/lat/lng/bearing/pitch`) and the tour stop (`stop=n`) into the URL hash, and reopening the link restores both. A full director adds keyframe timing, easing, and narration, and should read tours from a data file rather than code (R-I4).
5. **A guided route through the Anglican parishes of Canterbury.** The pilot's eight stops are a sketch of this route from OpenStreetMap alone. A route keyed to parishes rather than buildings needs the consent-gated Anglican parish series described in the layer-families design; it stays a standalone submap until consent clears ([layer families](layer-families-design-2026-08-29.md)).
6. **Constellation view.** At low zoom on the globe, the project's overview tiles already read as a constellation of coloured points; a night-style basemap would make this the opening image of the immersive page. Needs a second basemap source (OpenFreeMap's dark style is keyless) and a ruling only if it departs from the OSM-tiles ruling for this page.
7. **Accessibility fallback.** Reduced-motion users get `jumpTo` instead of `flyTo` in the pilot; the tour has Prev, Play and Next buttons, keyboard arrows and Escape. Still missing: a text itinerary listing every stop with its data fields, which is the screen-reader route and should ship with any public version.

## 5. What the pilot does (staged, keyless)

`apps/regions/_staged/immersive/` holds `index.html`, `immersive.js` and `immersive.css`. It is reachable only by URL and is not linked from any hub or region page. It loads MapLibre GL JS 6.9.0 as an ES module from jsdelivr; draws the OpenStreetMap raster basemap over Mapterhorn terrain (exaggeration 1.35 on desktop, 1.0 on phones) with a hillshade from a second Mapterhorn source; extrudes buildings from OpenFreeMap vector tiles from zoom 14 (hidden on phones); draws every place from the project tile server (`tiles.placemap.org/places`, source-layer `places`) in the shared runtime's religion colours; draws the NZ dated places as amber marks with name and start year labels; and offers four controls: Tour, Year, Globe and Copy link.

The tour is eight Canterbury Anglican churches keyed by OpenStreetMap way id, so every word on the title card comes from the dated-places product (name, religion, denomination, start year); only the camera per stop is authored. The order runs from Hanmer Springs through Rangiora, Tuahiwi, Papanui, St Michael and All Angels, the Transitional Cathedral and Addington to Akaroa. Each card links the OSM object and a "Stand at the door" Google Maps panorama link. Play auto-advances every seven seconds and can be paused, satisfying WCAG 2.2.2.

Verification on 2026-09-10, served from the repository root with `python3 -m http.server 8000` and driven by Playwright over the installed Google Chrome in headless mode (the shared interactive Chrome was in use by another session), 1280×820 and 390×844 viewports: initial globe view renders with terrain relief, project points and dated places; Tour opens stop 1 with the card "Church of the Epiphany – Hanmer Springs · christian · anglican — Recorded from 1901"; Next reaches stop 2 with the hash updated to `#view=16/-43.30457/172.58884/30/58&stop=2`; stop 6 renders the cathedral quarter with extruded buildings; the Year panel at 1870 hides later-dated places; reopening the copied link `...#view=16.4/-43.53237/172.64306/-40/64&stop=6` restores the camera and the card; and a phone-width `#stop=8` link flies to Akaroa with the card above the attribution. Console: the only errors are Mapterhorn 404s for sea tiles at zoom 6–8 (treated as empty) and the missing favicon; one MapLibre warning that fog is unsupported on the globe. Screenshots are in `.private/screens-2026-09-10/` (git-ignored). Not yet verified: a real phone, Safari, and a session long enough to exercise the iOS terrain memory issue.

Two design consequences surfaced in verification. First, MapLibre writes its own `view=` into the hash as soon as the map exists, so a link that carries only `stop=n` must be detected before the map is constructed; the pilot does this. Second, the pitched, terrain-draped raster basemap requests more OpenStreetMap tiles per view than a flat map; the OSMF tile usage policy permits "Normal interactive viewing by a human where the client requests only the tiles needed for the current viewport" and "may block access, without notice, if your usage degrades the service" ([policy](https://operations.osmfoundation.org/policies/tiles/)). The page sends a normal browser referer and caches per the browser; a public launch should still measure tile volume (R-I6).

## 6. Recommendation and staged plan

The recommendation is to build immersive exploration on the MapLibre stack the project already runs, keyless first, and to decline the CesiumJS and Google Photorealistic 3D Tiles route. The keyless path (MapLibre 6 globe, Mapterhorn terrain, OpenFreeMap buildings, the project's own tiles) covers globe, terrain, buildings and tours at zero cost and with no new key, as the pilot shows. The photorealistic route costs money on Cesium's reading of "funded educational research", requires a Cesium logo, and above all cannot legally sit with or near the OpenStreetMap map under Google's 3.2.3(e). A photorealistic page would have to be a separate Google-only surface, which cuts it off from every layer the project has built.

- **Stage 0 (done).** Staged keyless pilot at `apps/regions/_staged/immersive/`.
- **Stage 1 (keyless; no ruling beyond R-I1).** Harden the pilot: a text itinerary for screen readers; tours read from a `scene` JSON file with a schema (`schemas/immersive-scene.v1.json`) so a tour is data, not code; real-device tests on iPhone and Android; tile-volume measurement against the OSMF policy; a second tour outside Canterbury to prove the abstraction, as the layer-families design requires of any new layer kind.
- **Stage 2 (ruling R-I1 and R-I2).** Decide whether the immersive page stays standalone or becomes a mode of the shared runtime. A runtime mode means upgrading `region-map.js` from 3.6.1 to 6.x across about a hundred pages: module script loading, WebGL2 only, and a regression pass on every control. Standalone is cheaper and keeps the research maps untouched.
- **Stage 3 (rulings R-I3 and R-I7).** Street-level imagery: keep the link-out, add Mapillary with a free client token where coverage exists, and settle the existing Street View thumbnails against 3.2.3(e)(ii).
- **Stage 4 (ruling R-I8).** Interiors: a consent protocol for 360 photography, piloted with one or two congregations that ask for it, with marae and wāhi tapu excluded absent FPIC.
- **Deferred.** deck.gl flows (for relocation transitions and denominational spread over time), a night constellation basemap, WebXR.

## 7. Open rulings for JB

- **R-I1 Home.** Standalone immersive page (recommended) or a mode of the shared runtime after a MapLibre 6 upgrade.
- **R-I2 Terrain source.** Mapterhorn (recommended: built for browsers, Cloudflare-hosted, CC BY 4.0, self-hostable) or AWS Terrarium (LINZ 8 m for New Zealand, but its docs say the S3 endpoint is meant for EC2 traffic) or MapTiler (key, quota). Attribution text to carry in each case.
- **R-I3 Street View same-screen clause.** Google Terms 3.2.3(e)(ii) bars "Street View imagery and non-Google Maps on the same screen". The live popups show Street View thumbnails beside the OpenStreetMap map. Options: keep as is on a reading that a static thumbnail is not "Street View imagery" (UNVERIFIED and risky), move to link-out only (as the pilot), or move to Mapillary.

- **R-I5 Slider domain on the immersive page.** Confirm that a continuous year slider on a standalone page is compatible with R7 (census-wave slider on country maps).
