# Instructions for JW — review portal and decisions

Entry points (authorised for JB and JW):

- **[NZ review portal](https://religionmap.org/apps/regions/nz/review.html)**
- **[Vanuatu review portal](https://religionmap.org/apps/regions/vu/review.html)**

## What a decision means

- Decisions require an explicit choice plus a short note; there is no
  silent accept.
- `Accepted for export` means accepted into the reviewed export bundle
  for `pow` validation — NOT "on the map". Nothing reaches the master
  data or public map until it passes `pow` validate/stage/diff and a
  governed rebuild.
- `Changes requested` returns the task to the RA with your note as
  their next action.
- Unresolved notes (useful-but-incomplete evidence) appear in the queue
  too; they can be parked, returned, or accepted as partial evidence.
- System-test submissions can be marked rejected/excluded without
  entering the export path.
