# Instructions for research assistants — start here

You work from these pages directly; they are public and current. If a
page disagrees with something you were told in person or by email, the
page wins — tell JB so he can fix whichever is wrong.

## Your task documents

- **[NZ pilot task](../../ra-nz-pilot-task.md)** — the current
  assigned-workpack instructions (sign-in, saving, submitting,
  skipping).
- **[Map triage guide](../../ra-map-triage-guide.md)** — what to do
  with missing sites, duplicates, disappeared sites, complicated
  worship functions, and target-year checks.
- **[FAQ](../../../FAQ.md)** — plain-language answers on site identity,
  task generation, review, and what happens to your evidence.
- **[Lexicon](../../../LEXICON.md)** — project terms.

## The rules that never change

- Record what the source states, not what you infer; leave unknown
  dates blank (`YYYY`, `YYYY-MM`, or `YYYY-MM-DD` when known) and put
  uncertainty in the evidence note.
- `Save draft` while gathering; `Submit for review` when done;
  `Submit unresolved note` when evidence is useful but incomplete.
- "No building present" is different from "no longer used for
  worship" — the dropdowns keep them apart.
- Nominate missing places of worship through the task interface
  (`Nominate missing PoW`); nothing you enter changes the public map
  until it passes review.

Live entry points are linked from the repository README (verification
and review portals for NZ and Vanuatu).
