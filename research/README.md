# Research Notes

This directory holds working research notes for country selection, data-source
audits, and grant-aligned planning. These files should stay lightweight and
versioned.

Use these notes to record:

- candidate countries and why they matter for the grant
- source leads, access terms, licences, and retrieval paths
- available geographic units and boundary vintages
- religious constructs measured by each source
- likely map visualisations and downloadable products
- shifts from the grant plan and the reason for each shift

Keep raw data, large extracts, downloaded spreadsheets, and restricted materials
outside this directory. Use `data/`, object storage, or local ignored folders
with manifests instead.
