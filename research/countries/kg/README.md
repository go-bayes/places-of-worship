## Build recipe

No build recipe for affiliation mapping. Reopen only if the National Statistical Committee releases region-level religion tables or a documented administrative construct is accepted for a different map.

## Risks and open questions

Religion data are sensitive because state registration, minority Christian communities, Muslim movements, and local security concerns affect public reporting. National estimates should not be disaggregated with unofficial assumptions.

## Deep-history potential

Medium. The 1897 Russian Empire census, Soviet census materials, National Statistical Committee reports, State Commission on Religious Affairs registrations, mosque records, church records, and regional archives can support a historical site track.
