## First visualisation

Do not build a subnational affiliation map from the current public evidence. A separate registered-organisation or OSM site layer would need a different construct label.

## Build recipe

No build recipe for affiliation mapping. Reopen only if GSO or another official source releases province-level religion tables with clear categories and access terms.

## Risks and open questions

Vietnam's religion construct is affected by state recognition and registration, which means public counts can understate folk practice and unregistered communities. Combining registered-organisation data with census affiliation would mislabel the evidence.

## Deep-history potential

Medium. French Indochina census and administrative records, Vietnam National Archives centres, Government Committee for Religious Affairs registrations, Buddhist association records, church records, and provincial gazetteers may support a non-census historical site project.
